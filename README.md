# Unfold

Application mobile et web pour la consultation d'éphémérides et l'observation du ciel.

## Concept

Unfold est une application d'observation et de consultation destinée aux utilisateurs passionnés de ciel, d'astronomie et de phénomènes célestes. Le projet combine une interface mobile-first et une architecture web robuste.

## Stack

- React Native / Capacitor
- TypeScript
- Web moderne
- iOS et Android
